2️⃣ WALLET PROTECTION SYSTEM

🛡️ How It Works

The system calculates a "Max Safe Bid" to ensure you have enough money left for remaining players.

Formula: Max Safe Bid = Current Wallet - (Remaining Slots × ₹2,000)

📊 Example 1: Safe Bidding

Situation:

  • Current Wallet: ₹80,000
  • Players in Squad: 8/14
  • Remaining Slots: 6 players

Calculation:

Max Safe Bid = ₹80,000 - (6 × ₹2,000) = ₹80,000 - ₹12,000 = ₹68,000

Result: ✅ You can safely bid up to ₹68,000 for the current player

📊 Example 2: Blocked Bid

Situation:

  • Current Wallet: ₹25,000
  • Players in Squad: 10/14
  • Remaining Slots: 4 players
  • Player Base Price: ₹18,000

Calculation:

Max Safe Bid = ₹25,000 - (4 × ₹2,000) = ₹25,000 - ₹8,000 = ₹17,000

Result: ❌ System will BLOCK this bid because ₹18,000 > ₹17,000

Why? If you bid ₹18,000, you'll only have ₹7,000 left for 4 players (not enough!)
